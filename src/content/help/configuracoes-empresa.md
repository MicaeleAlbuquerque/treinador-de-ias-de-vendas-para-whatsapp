# Empresa

Na aba **Empresa** de `/app/settings` é possível ajustar dados que aparecem para todos os usuários da instância.

## Nome da empresa

Define o rótulo exibido no header do painel, do lado do menu do usuário. Use o nome comercial pelo qual o time reconhece a empresa.

## Permissões

Apenas **admins** podem editar esta aba. Members visualizam mas não podem alterar.
